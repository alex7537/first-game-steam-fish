# Fish Lab

一个语言驱动的程序化鱼类生成原型，也是“做出第一个鱼类游戏并上架 Steam”的起点。

当前进度（v0.4）：已完成文字/照片生成鱼、多鱼同缸、杂交遗传、物种图鉴、真实鱼模板与新种衍生，下一步是正式存档、成长互动、桌面封装和 Steam 发布。

当前版本是无依赖的单页 Demo：默认在浏览器内离线解析描述；也可以临时输入 Anthropic API key，使用 Claude 解析更自由的描述。API key 只存在页面内存中，刷新即失效。

版本变更记录见 [`change.md`](change.md)。

## v0.4 功能

- 开场生成三条随机鱼，鱼缸上限为 12 条
- 根据文字描述孵化新鱼，或生成完全随机的新鱼
- 点击选中鱼并查看基因，点击空白水面取消选择
- 将选中的鱼导出为 SVG，或从鱼缸放生
- 使用实体数组和帧率无关的游戏循环处理 wander、惯性、运动与碰壁
- 配对模式依次选择双亲，或选中一条鱼后 Shift+点击另一条快速繁殖
- 离散基因随机继承，连续基因混合并加入高斯噪声，颜色在 HSL 空间沿最短弧插值
- 双亲共有部件有 90% 概率遗传，单方部件为 55%；新部件有 12% 概率突变，尾巴为 5%
- 普通、稀有、史诗、传说四级稀有度，以及野生/第 N 代谱系显示
- 物种图鉴按离散性状去重，可复育物种并导入/导出 JSON
- 游戏循环异常后仍会续帧，异常实体会重置；页面脚本错误通过红色提示显示
- 离线模式可识别常用关键词，并可通过“小丑鱼”“锦鲤”等物种名直接命中真实模板；可选的 API Key 模式使用 Claude 解析
- 真实鱼类馆提供 10 个手工调校的物种模板，可作为育种母本重复入缸
- 选中鱼后可定向衍生“新种”：色相漂移、1–2 个性状变化并增减特殊部件
- 配置 API Key 后可上传 JPEG、PNG、GIF 或 WebP 照片，由 Claude 视觉转成基因

## 玩法

输入鱼类描述后点击“孵化新鱼”。未配置 API Key 时使用本地关键词解析；配置后使用 Claude 解析。点击“随机变异”会直接生成一条随机鱼。

点击“💕 配对繁殖”进入配对模式，再依次点击两条鱼；后代会在双亲中间诞生。也可以先选中一条鱼，再按住 Shift 点击另一条快速繁殖。

选中一条鱼后点击“🧬 衍生新物种”，可以从该母本定向产生新种：色相必然漂移 30–90°、改变 1–2 个离散性状，并增加或移除一个特殊部件。真实鱼类馆中的 10 个模板可以直接点击入缸。

“📷 照片转基因”需要先配置 API Key，支持不超过 7 MB 的 JPEG、PNG、GIF 和 WebP 图片。

页面底部的物种图鉴会自动收录孵化过的物种。点击图鉴卡片可以复育该物种。图鉴当前只保存在内存中，刷新页面会清空，养出稀有物种后请先导出 JSON。

真实鱼类馆中的模板使用现有基因字段近似表达外形：例如小丑鱼的橙白条纹、斗鱼的丝带尾和帆状背鳍、锦鲤的红斑和吻须、鮟鱇的发光诱饵与獠牙、河豚的圆胖尖刺，以及霓虹灯鱼的蓝身红腹和微光。它们是游戏化母本，不是生物学数据模型。

> 浏览器直连 API 会让 key 暴露给页面脚本和浏览器扩展，只适合本地原型。正式发布时应改用后端代理。

## 运行

直接用浏览器打开 `index.html`，或者在项目目录启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 当前架构

```text
文字描述 ──► localParse() / Claude ──┐
真实模板 ──► realGene() ─────────────┤
鱼类照片 ──► Claude Vision ─────────┤
选中母本 ──► deriveGene() ──────────┼──► FishGene（身份与谱系）
双亲基因 ──► crossGenes() ──────────┘          │
                                                ├──► speciesKey() ──► CODEX 图鉴
                                                ▼
                                          FISHES 实体数组
                                                │
                                   tick(dt) ──► 运动状态 + DOM/SVG 渲染
```

原型暂时放在单个 `index.html` 中，便于直接部署到 GitHub Pages。每条实体将不变的 `gene` 与逐帧变化的运动状态分开保存。玩法确定后再拆分渲染、数据和游戏逻辑。
